# Contributing

Contributions are welcome.

Before making larger changes, please open an issue or discuss the change with the maintainer first.

When contributing:

* Keep changes focused and reasonably small.
* Follow the existing project structure and conventions.
* Prefer simple solutions and avoid unnecessary dependencies.
* Add or update tests where appropriate.
* Never commit credentials, tokens, private keys, or other secrets.

Submit changes through a pull request.

The maintainer has final responsibility for reviewing and merging contributions.
